# JobTrack – Job Application Tracker

## Project Overview

JobTrack is a responsive web application designed to help job seekers organise and manage their job applications in one place.

Users can track application statuses, interview dates and job opportunities without relying on spreadsheets or scattered notes.

## Target Users

Job seekers who need a simple way to manage multiple job applications and monitor their progress.

## Features

- **Dashboard:** Displays total applications, upcoming interviews, offers received and rejected applications.
- **Add Application:** Create a new job application record.
- **View Applications:** Display application details in a responsive table or mobile card layout.
- **Edit Application:** Update existing application details.
- **Delete Application:** Remove an application from JSONBin with a confirmation dialog.
